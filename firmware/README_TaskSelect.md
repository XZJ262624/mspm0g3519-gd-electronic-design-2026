# 六任务选择与上电安全说明

## 按键接线

- SW1（确认）：PB26，按下时接 GND。
- SW2（选择）：PB27，按下时接 GND。
- 两个输入均由 SysConfig 配置为内部上拉，松开为高电平，按下为低电平。

## 使用方法

1. 上电后底盘保持停机，任务号默认是 1。
2. 每次按下并松开 SW2，任务号按 `1 -> 2 -> ... -> 6 -> 1` 循环。
3. 按下并松开 SW1 后锁定任务号，不能再次修改。
4. 确认时通过现有 UART1 发送三个原始字节：

   `0xB2 0x2B task_number`

5. 确认时任务计时从 0 开始，同时允许巡线任务运行。

## 屏幕

- 第一行：`RUNTIME` 和本次程序运行时间。
- 第二行：`TASK n` 和已选任务的任务计时。
- 任务未确认时任务计时保持 `00:00:00.000`。
- 黄色任务号表示尚未确认，绿色任务号表示已经锁定。

## 电机上电安全

软件初始化先把 PB3、PB12、PB13、PB4 四个 AT8236 控制脚配置为 GPIO
低电平，再初始化 TIMA0。PWM 计数器以四路 0 占空比运行稳定后，控制脚才
切回 TIMA0 外设功能。任务确认前速度闭环保持禁用。

D157B 原理图中 AIN1、AIN2、BIN1、BIN2 没有板载下拉。如果要求在 MCU
复位尚未执行任何代码的瞬间也绝对不产生抖动，建议在这四个控制输入上分别
增加一个 10 kOhm 下拉电阻。
